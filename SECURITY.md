# Security Policy

## Scope

This repository is an engineering portfolio project, not a production safety system.

## Secrets

Never commit:

- API keys;
- access tokens;
- credentials;
- `.env` files;
- private logs;
- customer or employer data.

Use `.env.example` only as a template.

## Confidentiality

Do not open issues or pull requests containing real plant names, tag names, alarm histories, screenshots, proprietary procedures, internal failure-mode libraries, or customer documents.

## Safety

The application must not be used to bypass plant procedures, interlocks, protection systems, permits, OEM guidance, or qualified engineering review.

## Reporting

For a security concern, use a private GitHub security advisory where available rather than a public issue.
