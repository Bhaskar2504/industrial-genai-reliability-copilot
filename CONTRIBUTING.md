# Contributing

Contributions should preserve the project's core principles:

1. Engineering usefulness before demo novelty.
2. Synthetic or clearly licensed public data only.
3. Evidence must be traceable.
4. Generated hypotheses must remain distinguishable from verified facts.
5. Safety-sensitive outputs require human review.
6. Evaluation must include failures, not only successful examples.
7. Releases must correspond to working, reproducible capability.

## Pull requests

A pull request should explain:

- the engineering problem being addressed;
- what changed;
- how it was tested;
- any new safety or hallucination risk;
- data/source provenance;
- limitations that remain.

Do not add proprietary or confidential material.
