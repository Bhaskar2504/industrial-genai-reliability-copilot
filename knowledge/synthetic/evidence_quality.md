# Synthetic Engineering Note — Evidence Quality Before Diagnosis

**Provenance:** Synthetic document written specifically for this portfolio project.

Before using industrial time-series evidence for diagnosis, check whether the asset is operating in the expected state, timestamps are aligned, units are correct, tags map to the intended equipment, values are not flat-lined or missing, and obvious maintenance/startup/changeover periods are understood.

A statistically unusual point is not automatically a failure. Persistence, operating context, multivariable consistency, and physical plausibility should be considered together.
