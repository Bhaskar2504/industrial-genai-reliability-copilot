# Synthetic Engineering Note — Sensor Disagreement

**Provenance:** Synthetic document written specifically for this portfolio project.

One sensor deviating from otherwise consistent peer measurements or process relationships can indicate an instrumentation problem, but disagreement alone does not prove sensor failure. The engineer should consider sensor range, calibration status, installation effects, wiring, signal conditioning, process gradients, redundancy design, and whether the compared measurements should physically agree under the current operating state.

A reliability copilot should state the instrumentation hypothesis as provisional and recommend checks that could distinguish a real process deviation from a measurement issue.
