# Public knowledge sources

No public documents are bundled in v0.1.

When public material is added in v0.3, every source must have:

- a stable source URL;
- publisher/owner;
- license or usage basis;
- retrieval date;
- document version/date when available;
- a note describing whether redistribution is allowed.

If redistribution is not clearly permitted, store metadata and ingestion instructions rather than copying the document into this repository.
