# Decision 0001 — Build capability in visible releases

**Status:** Accepted

The project will not publish a fabricated `v1.0` implementation on day one. It will progress through structured prompting, evaluation, retrieval, tools, guardrails, and observability as separately testable releases.

Reason: the repository is intended to demonstrate engineering and AI-system judgment. A transparent progression is more credible than a large untested scaffold presented as production-ready.
